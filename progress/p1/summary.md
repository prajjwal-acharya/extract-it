## What this phase covers

File ingestion path end-to-end: identity columns, SHA-256 hashing, multi-gate validation,
`IngestionOrchestrator`, FastAPI upload route, local filesystem trigger, and the DB/MinIO
wiring. All pipeline/LLM logic remains stubbed — P1 ends at `status="queued"`.

**Production hardening (post-functional):** atomicity via compensating delete, race-safe
idempotency via `IntegrityError` recovery, PyMuPDF resource cleanup, folder-watch settle
strategy, and structured lifecycle logging.

## IngestionOrchestrator — sequence

```
1. validate(data, filename)          → ValidationError on failure (no I/O)
2. compute_sha256(data)              → hash_hex
3. _find_by_hash(hash_hex)          → return (existing_id, True) if duplicate
4. sanitize_filename(original)      → safe_name
5. uuid4()                          → document_id, object_key = raw/{uuid}.{ext}
6. _store.put(object_key, data)     → MinIO write
7. _bootstrap(...)                  → DB INSERT
   └─ on IntegrityError             → rollback, re-query winner, raise _DuplicateHashError
   └─ on any failure                → _safe_delete(object_key) [compensating action]
8. _dispatch(doc_id, name, key)     → optional pipeline trigger
```

---

## Production hardening

### Atomicity (P1)
After `_store.put()`, `_bootstrap()` is wrapped in `try/except`. Any DB failure triggers
`_safe_delete(object_key, reason="db_failure")` before re-raising. Delete errors are logged
as `OrphanCleanupFailed` and suppressed so they never mask the root cause.

**Guarantee:** No orphan MinIO object survives a DB failure.

### Concurrent idempotency (P2)
`_bootstrap()` catches `sqlalchemy.exc.IntegrityError` specifically, rolls back, re-queries
for the winner's row, and raises `_DuplicateHashError(existing_id)`. The caller deletes the
orphan object it already wrote and returns `(existing_id, True)`.

**Guarantee:** Concurrent identical uploads never produce HTTP 500; one wins, one returns
`duplicate=true` cleanly.

### Resource cleanup (P3)
- `fitz.Document` wrapped in `try/finally: doc.close()` — released on success and on error.
- Folder-watcher callback uses `with open(path, "rb") as fh` — no unclosed file handles.
- All SQLAlchemy sessions closed in `finally` blocks.

### Folder-watch settle strategy (P4)
`_NewFileHandler._settle_and_call()` polls `os.path.getsize()` in a daemon thread until the
size is stable for one full `settle_secs` interval. A file that disappears mid-settle is
silently skipped. `WATCH_SETTLE_SECS` defaults to `1.0s` and is configurable via `.env`.

### Structured logging (P5)
Every ingest emits named lifecycle events on `io_pipeline.orchestrator` logger:

| Event | Fields |
|---|---|
| `UploadReceived` | filename, size, source |
| `ValidationStarted` | — |
| `ValidationSucceeded` | mime, ext, source |
| `IngestFailed` | reason, source, elapsed |
| `DuplicateDetected` | hash, existing_id, source, elapsed |
| `ObjectStored` | object_key, hash, source |
| `OrphanCleaned` / `OrphanCleanupFailed` | object_key, reason |
| `DocumentCreated` | document_id, object_key, hash, source, elapsed |
| `DispatchStarted` | document_id, source |

Trigger source is passed as `source=` kwarg: `"http"`, `"folder_watch"`, or `"shim"`.

## Key decisions

| Decision | Rationale |
|---|---|
| Partial unique index `WHERE hash IS NOT NULL` | Prevents duplicate rows for the same content without breaking existing NULL hashes (pre-migration rows) |
| `IntegrityError` catch + re-query (not SELECT-then-INSERT) | SELECT-then-INSERT has a TOCTOU race; letting the DB enforce uniqueness and catching the error is the correct pattern |
| `_safe_delete` swallows its own errors | If MinIO is also down, we want the original DB error to propagate, not a secondary MinIO error; orphan logged as `OrphanCleanupFailed` for manual remediation |
| Validate before hash (not hash before validate) | Validation is stateless and cheap; hashing corrupted or partial PDFs would waste cycles and could still fail at the PDF check gate anyway |
| `_DuplicateHashError` as private exception | Keeps the concurrent-duplicate signal internal to the orchestrator; callers see only `(doc_id, True)` |
| Settle polling in daemon thread | Blocks the watchdog event thread otherwise, starving other events; daemon status ensures it doesn't prevent clean shutdown |
| `source=` keyword-only arg on `ingest()` | Doesn't change existing call sites (defaults to `"unknown"`); adds trigger provenance to every log line without breaking API |
| doc_type regex: `^(?P<doc_type>.+)_(?P<entity_id>[^_]+)_(?P<date>\d{8})\.(?P<ext>\w+)$` | Greedy `.+` absorbs internal underscores in compound names (e.g. `bank_statement`); `entity_id` is `[^_]+` (no underscores) so the greedy group terminates at the correct `_` boundary |
| `minio_client` fixture: testcontainers `MinioContainer`, unique bucket prefix | Avoids dev MinIO pollution; simpler than shared state cleanup |
| `postgres_session` fixture: `pgvector/pgvector:pg16`, `CREATE EXTENSION vector` before `create_all` | Must match production image; `create_all` fails on `Vector(768)` without the extension |
| `get_db()` returns `Generator` not bare `Session` | FastAPI DI requires a generator (yield) to guarantee session close even on exceptions |

## Remaining known risks

| Risk | Severity | Notes |
|---|---|---|
| Orphan on `_safe_delete` failure | Low | Logged as `OrphanCleanupFailed`; requires manual MinIO cleanup. Fixable with an outbox table or saga log, but out of P1 scope. |
| `GCSStore.delete()` raises `NotImplementedError` | Low | GCP path untested; acceptable until P9. |
| Filename length not bounded | Low | `sanitize_filename` doesn't cap length; a very long filename stores as-is in `filename` column. |
| `ingest_file` shim has no dispatch | Intentional | Shim is for seeding/testing only. Documents ingested via shim reach `current_phase="ingested"` but pipeline is not triggered. |
